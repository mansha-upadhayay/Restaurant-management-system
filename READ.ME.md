 Restaurant Management System

 About the Project

This is a simple restaurant management system made using Python.

I made this project as a part of my VITyarthi Python Essentials course. The main purpose of the project is to practice Python concepts like functions, loops, lists, dictionaries, JSON files and modules.

The program allows the user to view the menu, order food, update the menu and add reviews.

 Features

 View restaurant menu
 Order one or more food items
 Automatically calculate the total bill
 Add new items to the menu
 Update item prices
 Remove items from the menu
 Add reviews and ratings

 Files Used


main.py
menu.py
update_menu.py
reviews.py
menu.json
README.md


 main.py

This is the main file of the project. It shows the main menu and connects the different parts of the program.

 menu.py

This file is used for displaying and handling the restaurant menu.

 update_menu.py

This file is used to add, update and remove menu items.

 reviews.py

This file is used to take reviews and ratings from the user.

 menu.json

This file stores the menu items and review data.

 How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure all the Python files  are in the same folder.
4. Run `main.py`.

  python
python main.py
